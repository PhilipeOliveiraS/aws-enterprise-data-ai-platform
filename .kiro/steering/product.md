# Product Overview: TasKiro

## Business Purpose & Vision
TasKiro is an enterprise-grade, high-performance task and sprint management system designed for engineering and platform teams. It delivers an ultra-fast, responsive user experience inspired by a Cyberpunk terminal interface.

## Core Features & Workflows
- **Interactive Kanban Board**: Dynamic task progression across columns (`todo`, `in_progress`, `review`, `done`).
- **Subtask Lifecycle**: Granular task breakdown with real-time completion progress indicators and cascading integrity.
- **Sprint Telemetry & Analytics**: Live velocity calculations and priority throughput metrics.
- **Enterprise Security**: User-isolated workspaces with Argon2/bcrypt password hashing and JWT authentication.
